# Space42 — Brand and Communications Guidelines

Static site. No build step.

## Deploy on Vercel
1. Upload this folder to a Git repo (or drag it into vercel.com/new).
2. Framework preset: **Other**. Build command: *none*. Output directory: `.` (root).
3. Deploy. `index.html` is the entry point.

CLI alternative: `npm i -g vercel` then run `vercel --prod` inside this folder.

## Notes
- Internal edition: put it behind Vercel Password Protection / SSO if it must stay staff-only.
- Antarctica Expanded is a licensed font — keep the deployment internal or check the licence before making it public.
- Download buttons marked "available soon" are placeholders (href="#").
